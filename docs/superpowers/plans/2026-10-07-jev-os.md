# Jev OS Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn Suica OS into Jev OS — Jev composes each app's UI live from the prompt, Gemini writes its content, and every trace of crypto, saving and publishing is gone.

**Architecture:** Jev's money question `fn` becomes `shape` (what the content is). A manifest is now `shell × shape × vibe × scene + prompt`. The window opens instantly with a skeleton bundle for that shape; `POST /api/content` asks Gemini Flash for JSON matching a per-shape zod schema and returns a `Bundle` the existing shells already render. Apps live only in open windows. Crypto modules, routes, dialogs and deps are deleted; generated shells keep their sandbox and move to a local-only disk cache.

**Tech Stack:** Next.js 16 (app router), React 19, TypeScript, zod 4, `@typesafe-ai/sdk` (Jev via Vercel AI Gateway), Gemini REST API (content + images), GSAP, vitest (added in Task 1). Package manager: **pnpm only**. App lives in `web/`.

**Spec:** `docs/superpowers/specs/2026-10-07-jev-os-design.md`

## Global Constraints

- Always `pnpm` / `pnpm exec` / `pnpm dlx` — never npm/npx/yarn. All commands run from `web/` unless stated.
- Product name is **Jev OS** in every user-visible string. Logo keeps the mint `#7de3c4` accent on "OS".
- Every app is realtime and ephemeral: no saving, publishing, sharing, desktop app icons or folders.
- Jev: Vercel AI Gateway, model `typesafe-ai/jev`, key `AI_GATEWAY_API_KEY`. Offline classifier stays as fallback.
- Content: Gemini via `GEMINI_API_KEY`, model from `GEMINI_CONTENT_MODEL` (default chosen in Task 5). Images: existing `/api/image`.
- Content caps: ≤ 12 rows, ≤ 8 columns, ≤ 60 series points, ≤ 10 list items, grid ≤ 8×8, doc ≤ 2,000 chars.
- Generated code is an untrusted guest: `sandbox="allow-scripts"` (never `allow-same-origin`), no-network CSP.
- Tappy speaks only fixed templates (no LLM free text).
- Never print, log or commit `web/.env.local`. Do not edit it.
- Other Claude sessions (Orion, Athena) share this checkout — Task 0 announces the work; don't touch files outside this plan.
- `tsc` is expected to be red between Task 2 and Task 11 (the vocabulary change ripples through UI files that later tasks rewrite). Each task proves itself with its own vitest tests; **Task 12 onward must be `tsc`- and lint-clean.**
- The dev server may fail to compile between Task 6 (deletes `functions.ts`/`registry.ts`) and Task 10 (rewrites `brain.ts`, which still imports them). If a browser check in Task 8 or 9 hits a compile error in a file a later task owns, note it and run that check after Task 10 instead of patching the later task's file early.
- Generated-shell cache stays at the existing `web/.genshells/` (the spec's `.cache/shells` was a placeholder name; same behavior).

## Review Focus

1. **Gemini returns valid JSON that breaks a shell** (empty table, 1-point series, 30-char cell in a narrow column) → schema mins/maxes reject it at the API, shells never see it. Pinned by Task 3 schema tests (min/max cases).
2. **User mashes Enter / opens the same prompt twice / Start preview and window race** → one Gemini call per `(prompt, shell, shape, vibe, nonce)`; pinned by the cache test in Task 5 and the client dedupe test in Task 7.
3. **Gemini slow or down** → window shows skeleton then the error panel with Try again after ≤ 20 s, never a blank window or React crash; pinned by Task 7 `useContent` error-state test.
4. **Gibberish or empty prompt** ("asdfgh", "hi") → no app is drafted, Start menu shows "cannot find .exe"; pinned by Task 2 mock-classifier nonsense test and Task 6 `topCombos` empty test.
5. **Jev unreachable while demoing** → offline classifier answers and the Start menu shows an "offline" chip, so nothing claims Jev falsely; pinned by Task 8 manual check + Task 13 smoke asserting `source === "jev"` when online.

```ts
/**
 * Shared vocabulary between Jev (server), the offline classifier and the composer.
 * Every prompt = SHELL (a familiar Win98 program) × SHAPE (what the content is) × VIBE × SCENE.
 */

export const SHELL_KEYS = ["excel", "minesweeper", "doom", "paint", "weather", "notepad", "hologram", "explorer", "unspecified"] as const;
export type ShellKey = (typeof SHELL_KEYS)[number];
export type ConcreteShell = Exclude<ShellKey, "unspecified">;

export const SHAPE_KEYS = ["table", "list", "series", "gauge", "scene", "grid", "doc", "picture"] as const;
export type ShapeKey = (typeof SHAPE_KEYS)[number];

export const VIBES = ["serious", "playful", "roast", "hype", "chill"] as const;
export type Vibe = (typeof VIBES)[number];

export const SCENES = ["sparkle", "ticker", "storm", "rocket", "sakura", "pool", "fire", "none"] as const;
export type SceneKey = (typeof SCENES)[number];

export type Answer<T extends string> = {
  value: T;
  confidence: number;
  probabilities: Partial<Record<T, number>>;
};

export type IntentResult = {
  shell: Answer<ShellKey>;
  shape: Answer<ShapeKey>;
  vibe: Answer<Vibe>;
  scene: Answer<SceneKey>;
  signals: { nonsense: number };
  latencyMs: number;
  model: string;
  source: "jev" | "mock" | "none";
  cached?: boolean;
  error?: boolean;
};

export function noneResult(extra: Partial<IntentResult> = {}): IntentResult {
  const a = <T extends string>(value: T): Answer<T> => ({ value, confidence: 1, probabilities: { [value]: 1 } as Partial<Record<T, number>> });
  return {
    shell: a<ShellKey>("unspecified"),
    shape: a<ShapeKey>("list"),
    vibe: a<Vibe>("serious"),
    scene: a<SceneKey>("none"),
    signals: { nonsense: 1 },
    latencyMs: 0,
    model: "none",
    source: "none",
    ...extra,
  };
}

/** Top-k labels of a choice answer, most likely first. */
export function topK<T extends string>(a: Answer<T>, k: number): { value: T; p: number }[] {
  return (Object.entries(a.probabilities) as [T, number][])
    .sort((x, y) => y[1] - x[1])
    .slice(0, k)
    .map(([value, p]) => ({ value, p }));
}
```

```ts
const PREFIX_UNITS = new Set(["$", "¥", "€", "£", "₹"]);
export function fmt(v: string | number | undefined, f: Fmt = "text", unit = "") {
  if (v === undefined || v === "") return "";
  if (typeof v !== "number" || f === "text") return `${v}`;
  const n = f === "pct" ? `${v.toLocaleString("en-US", { maximumFractionDigits: 1 })}%` : v.toLocaleString("en-US", { maximumFractionDigits: 2 });
  if (!unit) return n;
  return PREFIX_UNITS.has(unit) ? `${unit}${n}` : `${n} ${unit}`;
}
```

```ts
import { z } from "zod";
import type { Bundle } from "@/lib/compose/shapes";
import type { ShapeKey } from "@/lib/intent/types";

export class ContentError extends Error {}

const s = (max: number) => z.string().min(1).max(max);
const opt = (max: number) => z.string().max(max);
const head = { title: s(60), subtitle: s(120) };

/** What Gemini must return per shape. Every field required (Gemini JSON mode is stricter with required-only objects). */
export const RAW = {
  table: z.object({
    ...head,
    columns: z.array(z.object({ label: s(24), fmt: z.enum(["num", "pct", "text"]), unit: opt(6) })).min(1).max(8),
    rows: z.array(z.array(opt(60)).max(8)).min(1).max(12),
  }),
  list: z.object({
    ...head,
    items: z.array(z.object({ title: s(60), subtitle: opt(120), right: opt(20), tone: z.enum(["up", "down", "warn", "none"]) })).min(1).max(10),
  }),
  series: z.object({ ...head, label: s(40), unit: opt(6), points: z.array(z.number()).min(4).max(60) }),
  gauge: z.object({
    ...head,
    value: z.number().min(0).max(1),
    label: s(40),
    caption: s(120),
    forecast: z.array(z.object({ day: s(12), value: z.number().min(0).max(1) })).max(7),
  }),
  scene: z.object({
    ...head,
```

```ts
import type { Bundle } from "@/lib/compose/shapes";
import { buildPrompt, type ContentRequest } from "./prompt";
import { ContentError, jsonSchemaFor, toBundle } from "./schema";

export type { ContentRequest };
export type GeminiCall = (p: { system: string; user: string; schema: object }) => Promise<string>;

const DEFAULT_MODEL = "REPLACE_WITH_MODEL_FROM_STEP_1";
const TIMEOUT_MS = 20_000;
const CACHE_MAX = 200;

const cache = new Map<string, Bundle>();
const inflight = new Map<string, Promise<Bundle>>();
const cacheKey = (r: ContentRequest) => [r.prompt.trim().toLowerCase(), r.shell, r.shape, r.vibe, r.nonce].join("|");

export const gemini: GeminiCall = async ({ system, user, schema }) => {
  const key = process.env.GEMINI_API_KEY;
  if (!key) throw new Error("GEMINI_API_KEY is not set");
  const model = process.env.GEMINI_CONTENT_MODEL || DEFAULT_MODEL;
  const r = await fetch(`https://generativelanguage.googleapis.com/v1beta/models/${model}:generateContent`, {
    method: "POST",
    headers: { "x-goog-api-key": key, "content-type": "application/json" },
    body: JSON.stringify({
      systemInstruction: { parts: [{ text: system }] },
      contents: [{ role: "user", parts: [{ text: user }] }],
      generationConfig: { responseMimeType: "application/json", responseJsonSchema: schema, temperature: 0.9 },
    }),
    signal: AbortSignal.timeout(TIMEOUT_MS),
  });
  const j = (await r.json()) as { error?: { message: string }; candidates?: { content?: { parts?: { text?: string }[] } }[] };
  if (!r.ok) throw new Error(`gemini ${r.status}: ${j.error?.message?.slice(0, 160)}`);
  const text = j.candidates?.[0]?.content?.parts?.map((p) => p.text ?? "").join("") ?? "";
  if (!text) throw new ContentError("gemini returned no text");
  return text;
};

async function once(req: ContentRequest, call: GeminiCall): Promise<Bundle> {
  const { system, user } = buildPrompt(req);
  const raw = await call({ system, user, schema: jsonSchemaFor(req.shape) });
  let json: unknown;
  try {
    json = JSON.parse(raw);
  } catch {
    throw new ContentError("not JSON");
  }
  return toBundle(req.shape, json);
}

/** Gemini → validated bundle. One retry on a bad answer. Cached and de-duplicated per request. */
export function generateContent(req: ContentRequest, call: GeminiCall = gemini): Promise<Bundle> {
  const key = cacheKey(req);
  const hit = cache.get(key);
  if (hit) return Promise.resolve(hit);
  const running = inflight.get(key);
  if (running) return running;
  const p = (async () => {
    let b: Bundle;
    try {
      b = await once(req, call);
    } catch (e) {
      if (!(e instanceof ContentError)) throw e;
      b = await once(req, call);
    }
    if (cache.size >= CACHE_MAX) cache.delete(cache.keys().next().value!);
    cache.set(key, b);
    return b;
  })().finally(() => inflight.delete(key));
  inflight.set(key, p);
  return p;
}
```

```ts
export function resolveShell(shell: ShellKey, shape: ShapeKey): ConcreteShell {
  if (shell !== "unspecified" && SHELL_META[shell as ConcreteShell]?.accepts.includes(shape)) return shell as ConcreteShell;
  return SHAPE_DEFAULT_SHELL[shape];
}

let seq = 0;
export const newId = (p = "app") => `${p}_${Date.now().toString(36)}_${(seq++).toString(36)}`;

export type Combo = { shell: ConcreteShell; shape: ShapeKey; p: number };

/** Top shell × shape combos for the Start menu. Jev answers both independently; joint p = product. */
export function topCombos(intent: IntentResult, k = 3, prompt?: string): Combo[] {
  if (intent.signals.nonsense > 0.6 && !(prompt && detectProgram(prompt))) return [];
  const shells = Object.entries(intent.shell.probabilities).sort((a, b) => b[1]! - a[1]!).slice(0, 3) as [ShellKey, number][];
  const shapes = Object.entries(intent.shape.probabilities).sort((a, b) => b[1]! - a[1]!).slice(0, 3) as [ShapeKey, number][];
  const seen = new Set<string>();
  const out: Combo[] = [];
  for (const [sh, ps] of shapes)
    for (const [s, pl] of shells) {
      const shell = resolveShell(s, sh);
      const key = `${shell}:${sh}`;
      if (seen.has(key)) continue;
      seen.add(key);
      out.push({ shell, shape: sh, p: ps * pl });
    }
  return out.sort((a, b) => b.p - a.p).slice(0, k);
}

const titleFrom = (prompt: string) => {
  const t = prompt
    .trim()
    .replace(/^(make|open|show me|create)\s+/i, "")
    .replace(/^(an?\s+)?(excel|minesweeper|doom|paint|weather|notepad|3d|hologram|explorer)\s+((of|but|with|about|for)\s+)?/i, "")
    .replace(/^(of|but|about|an?|the)\s+/i, "");
  const s = t.charAt(0).toUpperCase() + t.slice(1);
  return s.length > 40 ? `${s.slice(0, 39)}…` : s || "Untitled";
};

export function draftManifest(opts: { prompt: string; intent: IntentResult; params: Params; combo?: Combo }): AppManifest {
  const { prompt, intent } = opts;
  const shape = opts.combo?.shape ?? intent.shape.value;
  const shell = opts.combo?.shell ?? resolveShell(intent.shell.value, shape);
  const params = shape === "picture" && !opts.params.image ? { ...opts.params, image: prompt.trim() } : opts.params;
  const meta = SHELL_META[shell];
  return {
    id: newId(),
    title: `${meta.label} · ${titleFrom(prompt)}`,
    icon: meta.icon,
    shell,
    shape,
    vibe: intent.vibe.value,
    scene: intent.scene.value,
    prompt,
    params,
    description: `${meta.label} — ${prompt.trim()}`,
    jevMs: intent.latencyMs,
    jevSource: intent.source,
  };
}
```

```ts
import type { AppManifest } from "@/lib/compose/compose";
import type { Bundle } from "@/lib/compose/shapes";

const cache = new Map<string, Promise<Bundle>>();

/** One /api/content call per (app content identity, nonce). The Start preview and the window share it. */
export function fetchContent(app: AppManifest, nonce: number, f: typeof fetch = fetch): Promise<Bundle> {
  const key = [app.prompt.trim().toLowerCase(), app.shell, app.shape, app.vibe, nonce].join("|");
  const hit = cache.get(key);
  if (hit) return hit;
  const p = (async () => {
    const res = await f("/api/content", {
      method: "POST",
      headers: { "content-type": "application/json" },
      body: JSON.stringify({ prompt: app.prompt, shell: app.shell, shape: app.shape, vibe: app.vibe, nonce }),
      signal: AbortSignal.timeout(25_000),
    });
    const j = (await res.json().catch(() => ({}))) as { bundle?: Bundle; error?: string };
    if (!res.ok || !j.bundle) throw new Error(j.error ?? `content ${res.status}`);
    return j.bundle;
  })();
  cache.set(key, p);
  p.catch(() => cache.delete(key));
  return p;
}
```

```ts
/** End-to-end check against a running dev server: Jev composes, Gemini fills. Usage: pnpm smoke [baseUrl] */
const BASE = process.argv[2] ?? "http://localhost:3000";
const PROMPTS = [
  "minesweeper but about cats", "excel of the best ramen in tokyo", "paint but roast my monday", "weather forecast for my mood",
  "notepad diary of a pirate", "3d chart of the tallest buildings", "top 10 sci-fi books", "doom but the enemies are my emails",
  "a list of weekend hikes near tokyo", "excel comparing coffee brewing methods", "poem about rain in notepad", "chart of world population",
  "pep talk for my exam", "minesweeper of haunted houses", "weather for my productivity", "draw a picture of mt fuji",
  "excel of solar system planets", "list of best anime of 2025", "notepad recipe for onigiri", "paint but a fortune for today",
];

type Intent = { shell: { value: string }; shape: { value: string }; vibe: { value: string }; source: string; latencyMs: number; signals: { nonsense: number } };
const SHAPE_SHELL: Record<string, string> = { table: "excel", list: "explorer", series: "explorer", gauge: "weather", scene: "paint", grid: "minesweeper", doc: "notepad", picture: "paint" };

let failed = 0;
const lat: number[] = [];
for (const prompt of PROMPTS) {
  const i = (await (await fetch(`${BASE}/api/intent`, { method: "POST", headers: { "content-type": "application/json" }, body: JSON.stringify({ text: prompt }) })).json()) as Intent;
  if (i.source !== "jev") { failed++; console.log(`✗ ${prompt}: intent source=${i.source}`); continue; }
  lat.push(i.latencyMs);
  const shell = i.shell.value === "unspecified" ? SHAPE_SHELL[i.shape.value] : i.shell.value;
  if (i.shape.value === "picture") { console.log(`✓ ${prompt}: ${shell}/picture ${i.latencyMs}ms (image route not exercised)`); continue; }
  const t0 = Date.now();
  const r = await fetch(`${BASE}/api/content`, { method: "POST", headers: { "content-type": "application/json" }, body: JSON.stringify({ prompt, shell, shape: i.shape.value, vibe: i.vibe.value }) });
  const j = (await r.json()) as { bundle?: { title: string }; error?: string };
  if (!r.ok || !j.bundle) { failed++; console.log(`✗ ${prompt}: content ${r.status} ${j.error}`); continue; }
  console.log(`✓ ${prompt}: ${shell}/${i.shape.value} jev ${i.latencyMs}ms · content ${Date.now() - t0}ms · "${j.bundle.title}"`);
}
lat.sort((a, b) => a - b);
console.log(`\nJev p50 ${lat[Math.floor(lat.length / 2)] ?? "-"}ms · p90 ${lat[Math.floor(lat.length * 0.9)] ?? "-"}ms · ${failed} failed`);
process.exit(failed ? 1 : 0);
```
Note: the shell fallback above is only for routing the smoke request; if the named shell can't render the shape the API still validates the content — that's fine for this check.
